Build and Deployment

Our application uses an automated build and deployment process with Jenkins.

  1. Developers write application code.
  2. Code is uploaded to a Git repository.
  3. Jenkins retrieves the latest code.
  4. The application is built and tested.
  5. The application is deployed to a server.
